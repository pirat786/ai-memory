AI Memory

Unified local-first memory for AI coding agents (Antigravity, Claude Code, Codex, Cursor) without MCP.

What it does

  • Local SQLite + FTS5: Stores project decisions, architecture notes, bug fixes, and global preferences on your device.
  • Fast CLI (aimem): Allows local AI agents to read project context and save new decisions directly.
  • Desktop App (Tauri 2): Native window, system tray, and automatic background sync.
  • Google Drive Sync: Optional cross-device synchronization using your private Google Drive drive.appdata folder.
